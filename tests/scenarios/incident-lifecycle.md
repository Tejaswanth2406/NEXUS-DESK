# Incident lifecycle scenarios

1. VPN outage: category network, impact 2, urgency 2, expected priority 2, team Network Operations.
2. Account lockout: category identity, impact 1, urgency 1, expected priority 1 and review.
3. Printer failure: category hardware, impact 3, urgency 3, expected priority 4.
4. Invalid submission: missing description, expected HTTP 400 and no incident row.
5. AI timeout: deterministic fallback, audit provider deterministic, user can review.
6. Malformed AI JSON: deterministic fallback, no sensitive value auto-applied.
