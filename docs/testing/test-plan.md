# Test plan

## Unit tests

Validation, priority matrix, classification, routing, AI schema validation and deterministic fallback.

## ATF

Incident form, insert/update Business Rules, employee/agent/manager/admin ACLs, notifications and escalation flows.

## Integration tests

OAuth, REST create/read contracts, Knowledge search, AI timeout/error, malformed AI output and regression scenarios.

## Exit criteria

- All focused tests pass.
- Portal production build succeeds.
- High-priority regression suite passes.
- Sensitive AI actions remain blocked until review.
- Evidence is attached to the PDI update set or test plan.
