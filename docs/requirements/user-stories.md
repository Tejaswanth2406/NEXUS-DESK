# User stories

- As an employee, I can submit an incident and receive a tracking number.
- As an employee, I can view status and assignment for my incidents.
- As an agent, I can triage incidents by priority and assignment group.
- As a manager, I can monitor MTTR, SLA compliance and workload.
- As an administrator, I can configure routing, priority and provider settings.
- As a reviewer, I can approve or override an AI-generated recommendation.
- As an integration consumer, I can submit and retrieve incidents with OAuth.
